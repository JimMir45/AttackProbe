## 1. 设计目标

### 1.1 解决的问题

| 问题 | 传统方式 | 码表方式 |
|------|---------|---------|
| 前后端状态不一致 | 各自硬编码 | 统一码表，前端动态获取 |
| 新增状态需改代码 | 改代码 + 发版 | 数据库配置，热生效 |
| 多语言支持 | 前端多套文案 | 码表存多语言 value |
| 状态含义不清晰 | 注释/文档 | 码表自带描述 |
| 两级架构码值不一致 | 集团省公司分别定义 | 统一码表同步 |

### 1.2 设计原则

- **统一管理**: 所有状态/枚举值归拢到码表
- **前后端共用**: 后端存储 code，前端展示 value
- **两级同步**: 集团码表下发省公司/专业公司，保证一致性
- **可扩展**: 支持动态新增类型和值
- **高性能**: 码表数据缓存，减少数据库查询

## 2. 数据模型

### 2.1 码表类型表 (dict_type)

```sql
-- 码表类型表: 定义码表分类
CREATE TABLE dict_type (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,

    -- 类型标识
    type_code VARCHAR(50) NOT NULL UNIQUE,    -- 类型代码: NodeType
    type_name VARCHAR(100) NOT NULL,          -- 类型名称: 节点类型

    -- 分类
    module VARCHAR(50),                        -- 所属模块: node | agent | sync | case | task | system

    -- 描述
    description VARCHAR(500),                  -- 类型描述

    -- 状态
    enabled BOOLEAN DEFAULT TRUE,
    system_builtin BOOLEAN DEFAULT FALSE,      -- 系统内置，不可删除

    -- 时间
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    INDEX idx_module (module),
    INDEX idx_enabled (enabled)
);
```

### 2.2 码表值表 (dict_value)

```sql
-- 码表值表: 定义具体的码值
CREATE TABLE dict_value (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,

    -- 关联类型
    type_code VARCHAR(50) NOT NULL,            -- 关联的类型代码

    -- 码值定义
    code INT NOT NULL,                         -- 数值代码: 1, 2, 3 (存储/传输用)
    key VARCHAR(50) NOT NULL,                  -- 字符串键: group, province (程序判断用)
    value VARCHAR(100) NOT NULL,               -- 显示值: 集团节点, 省公司节点 (界面展示用)
    value_en VARCHAR(100),                     -- 英文值: Group Node, Province Node

    -- 扩展
    extra JSONB,                               -- 扩展属性: {color: "#52c41a", icon: "check"}

    -- 排序
    sort_order INT DEFAULT 0,                  -- 排序号

    -- 状态
    enabled BOOLEAN DEFAULT TRUE,
    is_default BOOLEAN DEFAULT FALSE,          -- 是否默认值

    -- 时间
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    -- 约束
    UNIQUE INDEX idx_type_code (type_code, code),
    UNIQUE INDEX idx_type_key (type_code, key),
    INDEX idx_enabled (type_code, enabled),

    FOREIGN KEY (type_code) REFERENCES dict_type(type_code)
);
```

### 2.3 数据模型关系

```

│                            码表数据模型                                       │

│   ┌─────────────────────┐              ┌─────────────────────────────────┐  │
│   │ type_code (PK)      │──────1:N────▶│ type_code (FK)                  │  │
```

### 12.2 码表组件

```vue
<!-- components/DictTag.vue - 码表标签展示 -->
<template>
  <a-tag :color="tagColor">
    <template v-if="extra?.icon">
      <component :is="extra.icon" style="margin-right: 4px" />
    </template>
    {{ displayValue }}
  </a-tag>
</template>

<script setup lang="ts">
import { computed } from 'vue';
import { useDictStore } from '@/stores/dict';

const props = defineProps<{
  typeCode: string;
  code?: number;
  keyValue?: string;
}>();

const dictStore = useDictStore();

const item = computed(() => {
  if (props.code !== undefined) {
    return dictStore.getItemByCode(props.typeCode, props.code);
  }
  if (props.keyValue) {
    return dictStore.getItemByKey(props.typeCode, props.keyValue);
  }
  return null;
});

const displayValue = computed(() => item.value?.value || '');
const tagColor = computed(() => item.value?.extra?.color);
const extra = computed(() => item.value?.extra);
</script>
```
